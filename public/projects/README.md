# Imagens dos projetos

Coloque os prints/screenshots dos projetos nesta pasta com o nome exato abaixo
(aceita `.jpg`, `.jpeg`, `.png` ou `.webp`). Assim que o arquivo existir, ele
aparece automaticamente no site — nenhuma alteração de código é necessária.

| Projeto                              | Nome do arquivo esperado          |
|---------------------------------------|------------------------------------|
| Super Mario Galaxy                    | `super-mario-galaxy.jpg`           |
| TCC — Cubo Multissensorial            | `tcc-cubo-multissensorial.jpg`     |
| Passa a Bola                          | `passa-a-bola.jpg`                 |
| Clone Airbnb                          | `clone-airbnb.jpg`                 |
| Jogo do Número Secreto                | `jogo-do-numero-secreto.jpg`       |
| CodeDaily — Desafios Diários          | `codedaily-desafios-diarios.jpg`   |
| Screen Match Movies                   | `screen-match-movies.jpg`          |
| Cadastro de Jogadoras — CRUD          | `cadastro-de-jogadoras-crud.jpg`   |
| GameStore — Catálogo de Produtos      | `gamestore-catalogo-de-produtos.jpg`|
| Auto Escola                           | `auto-escola.jpg`                  |
| Carros                                | `carros.jpg`                       |
| Photo Portfolio                       | `photo-portfolio.jpg`              |

Recomendação: screenshots em 4:3 ou 16:9, pelo menos 1000px de largura.
Enquanto não houver imagem, o card mostra as iniciais do projeto como marca d'água.
